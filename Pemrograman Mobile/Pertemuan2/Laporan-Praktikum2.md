# praktikum menyiapkan lingkungan pengembangan dan memulai pemrograman Mobile (Reaact Native)#


## Tujuan Pembelajaran ##
Mahasiswa mampu:
1. menyiapkan lingkungan pengembangan dan memulai pemrograman mobile (React Native)
2. membuat aplikasi mobile dengan React Native
3. Menyelesaikan tugas CV sederhana dengan React Native

## Materi dan Laporan Praktikum ##
1. Menyiapkan lingkungan pengembangan dan memulai pemograman mobile (React Native)
    - memastikan instalasi Git bash
    - cek instalasi Git bash (git --version)
    - bukti verifikasi

    ![alt text](<Cuplikan layar 2026-09-14 105218.png>)
    - memastikan Node.JS dan NPM
        -Download dan intalasi Node.JS di https://nodejs.org/en/download/
        - Konfirmasi Node.JS dan NPM (node -v, npm -v)
        ![alt text](<Cuplikan layar 2026-09-14 110619.png>)

2. Membuat aplikasi / Projek baru dengan React Native Framework Expo Go
    - buka dan baca dokumentasi resmi link https://doc.expo.dev/
    - buka dan baca dokumentasi resmi link https://reacnative.dev/docs/getting-started
    - memulai membuat projek baru
    - open terminal chage directory ke pertemuan-2
    - masukkan perintah (npx create-expo-app ptmn2 --template blank)
    - bukti verifikasi    
    ![alt text](<Cuplikan layar 2026-09-14 113640.png>)    
    - running projek
        - cd ke ptmn2
        - npx expo start
        - instal Expo Go di Andoid atau IOS
        - bisa juga menggunakan web emulator di laptop / PC
        - setelah berhentikan (ctrl + c)
        - instal (npx expo install react-dom react-native-web)
        - npx expo start --web
        - konfirmasi
